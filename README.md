# dark-red-noctalia

​A clean, dark, and red-themed rice for Niri and CachyOS. Optimized for end-user laptops and PCs.

​🛠 Prerequisites
  
​To get this look, ensure you have the following installed:
​WM: Niri
​Terminal: Kitty
​System Monitor: Btop
​Fonts: Nerd Fonts (Required for icons)
​Status Bar/Fetch: Waybar, Fastfetch

​🚀 Installation
  
Clone this repository: git clone https://github.com/mhmd1233321/dark-red-noctalia.git

Copy the config files to your ~/.config/ directory: cp -r dark-red-noctalia/* ~/.config/

Restart Niri or log out and log back in to apply changes.
